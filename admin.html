Committee Schedule — Semester Update Tool

Make your changes below, preview them, then copy the result into committees-data.js on GitHub. Nothing here saves automatically — you must complete the last step for changes to go live.

How to update the schedule each semester

  1. Edit the fields below — semester name, and each committee's day, time, frequency, and color. Use "Add committee" for new ones and the red button to remove ones that no longer meet.
  2. Check the live preview at the bottom to make sure it looks right.
  3. Click "Generate updated file" — a box of text will appear.
  4. Click "Copy to clipboard".
  5. On GitHub, open committees-data.js in the repository, click the pencil (✎ edit) icon, select all the existing text and delete it, then paste in the copied text.
  6. Scroll down and click "Commit changes" on GitHub. The live schedule page updates automatically within a minute or two.
